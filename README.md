# CODESYS_3-Jointed-SCARA-System
Designed and developed a robotic manipulator project focused on robot kinematics, motion control, and industrial automation. The project explores the control and movement of a SCARA-type robotic system, with reference to CODESYS SoftMotion kinematic transformations.
